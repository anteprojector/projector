The shape

01

State complete

The agent is its state. Everything needed to run, resume, or reason about it is recoverable application state — no hidden context in a transcript.

02

Durable frame log

Every meaningful transition is a frame. Replay the log and you're back exactly where you were — inspect it, audit it, time-travel it.

03

Projections

Each actor sees the slice of state, tools, and instructions meant for them. Same world, different views — that's the whole trick.

04

Client/server unified

Client and server are typesafe representations of the same machine. No parallel schemas quietly drifting apart.

Why

Most agent frameworks are built around a message list: the transcript is the source of truth and everything else hangs off it. That holds up until the agent needs to be resumed, inspected, shared with a second actor, or rendered as a real app.

projector inverts it. Agents are multiplayer apps — the user and the LLM are just the first two actors. They share one model of the world, backed by a durable frame log, and each sees it through their own projection. All you need is state.

terminalprojector replay
$ projector replay --tail
0041  user.message   "add oat milk to the list"

0044  agent.say      "added — want the barista kind?"
